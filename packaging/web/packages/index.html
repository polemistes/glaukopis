Glaukopis, a first version to test

Be aware: The text below is AI generated, as is the code of Glaukopis. AI code can be good. AI text cannot. The first non-beta release of Glaukopis will not have AI generated texts, except for standard short text for features in the user interface. Version 0.1.0, built 6 October 2026. Glaukopis is where the work on an academic book or article is done: references, ideas in mind maps, writing, and the manuscript. Everything here is for testing: it will have faults, and your project files may not open in a later version. Keep what matters elsewhere as well.

Not signed. The installers for Windows and macOS carry no signature, so both systems warn before they run. On Windows, choose More info and then Run anyway. On macOS, open Glaukopis the first time by right-clicking it in Applications and choosing Open; if macOS says the app is damaged, run xattr -cr /Applications/Glaukopis.app in the Terminal and try again.

Spelling and other languages. No dictionaries of spelling come with Glaukopis, and Tesseract, which reads text in scans and pictures, comes with English only. The languages you need are imported in Glaukopis itself, under Settings › Spelling and under Tesseract in Settings › Programs: choose Show languages on the server and Import. They are fetched from this page.

Arch Linux

Packages for pacman, x86_64. Here Pandoc and the font Libertinus come from the repositories and are installed with Glaukopis as its dependencies; Tesseract, the dictionaries of Hunspell and the rest are optional, and pacman -Qi glaukopis says what each is for. 

sudo pacman -U glaukopis-0.1.0-17-x86_64.pkg.tar.zst
  • glaukopis-0.1.0-17-x86_64.pkg.tar.zst 27 MB

    The application. Depends on pandoc-cli and otf-libertinus, which pacman fetches. For reading scans and pictures, install tesseract and tesseract-data-eng. The system's dictionaries and Tesseract's data (hunspell-en_us, tesseract-data-nor and the like) are found as well as those imported.

  • glaukopis-server-0.1.0-17-x86_64.pkg.tar.zst 1.8 MB

    The collaboration server, for the one computer that is to pass changes between people writing in the same project at the same time. Nobody else needs it: Glaukopis works on its own. How to run it is in /usr/share/doc/glaukopis-server/server.md once installed.

Debian, Ubuntu and Fedora

Checking what you downloaded

SHA256SUMS lists the checksum of every installer and package above. In the folder you downloaded to, sha256sum -c SHA256SUMS --ignore-missing on Linux or shasum -a 256 -c SHA256SUMS --ignore-missing on macOS checks them; on Windows, Get-FileHash in PowerShell shows a file's checksum to compare. The checksums of the languages are in index.json.

Reading on, and reporting

The guide to Glaukopis is installed with it and can be read on GitHub: docs/guide.md. Faults, surprises and wishes are welcome by mail to develop@robertemilberge.no, or as issues at github.com/polemistes/glaukopis. Say which file you installed and what you did when it went wrong. The interface speaks many languages, most of them translated with the help of a language model and not yet read by people who speak them: a word that is wrong in yours is worth a line.

Glaukopis is free software under the GPL, version 3 or later. The dictionaries and the data for Tesseract have licences of their own, which come with them.
