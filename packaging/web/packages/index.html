Glaukopis, a first version to test

Version 0.1.0, built 5 October 2026. Glaukopis is where the work on an academic book or article is done: references, ideas in mind maps, writing, and the manuscript. Everything here is for testing: it will have faults, and your project files may not open in a later version. Keep what matters elsewhere as well.

Not signed. The installers for Windows and macOS carry no signature, so both systems warn before they run. On Windows, choose More info and then Run anyway. On macOS, open Glaukopis the first time by right-clicking it in Applications and choosing Open; if macOS says the app is damaged, run xattr -cr /Applications/Glaukopis.app in the Terminal and try again.

Windows

For Windows 10 and 11, 64-bit. Pandoc, Tesseract with its languages, the dictionaries of spelling and the fonts of Typst come with the installer: nothing else is needed. If the WebView2 runtime is missing, which is rare, the installer fetches it.

  • Glaukopis_0.1.0_x64-setup.exe 102 MB

    The usual installer. Installs for the person who runs it, without asking for an administrator, and puts Glaukopis in the Start menu. Choose this one unless you have a reason not to.

  • Glaukopis_0.1.0_x64_en-US.msi 148 MB

    The same application as a Windows Installer package, for installing for every user of the computer or through the tools of an institution. Needs an administrator.

macOS

For Macs with Apple silicon (M1 and later), macOS 11 or newer. There is no build for Intel Macs yet. As on Windows, Pandoc, Tesseract, the dictionaries and the fonts come with it.

  • Glaukopis_0.1.0_aarch64.dmg 98 MB

    A disk image. Open it and drag Glaukopis into Applications. Then open it the first time with a right-click, as said above.

Arch Linux

Packages for pacman, x86_64. Here Pandoc and the font Libertinus come from the repositories and are installed with Glaukopis as its dependencies; Tesseract and the rest are optional, and pacman -Qi glaukopis says what each is for. Install the application and the dictionaries of the languages you write in: 

sudo pacman -U glaukopis-0.1.0-16-x86_64.pkg.tar.zst \
  glaukopis-dictionaries-en-0.1.0-16-any.pkg.tar.zst
  • glaukopis-0.1.0-16-x86_64.pkg.tar.zst 25 MB

    The application. Depends on pandoc-cli and otf-libertinus, which pacman fetches. For reading scans and pictures, install tesseract and tesseract-data-eng, with the data of other languages as you need them.

  • glaukopis-dictionaries-en-0.1.0-16-any.pkg.tar.zst 0.7 MB

    Dictionaries for checking the spelling of English, American and British.

  • glaukopis-dictionaries-nb-0.1.0-16-any.pkg.tar.zst 1.5 MB

    Dictionary for Norwegian Bokmål.

  • glaukopis-dictionaries-nn-0.1.0-16-any.pkg.tar.zst 1.5 MB

    Dictionary for Norwegian Nynorsk.

  • glaukopis-server-0.1.0-16-x86_64.pkg.tar.zst 1.8 MB

    The collaboration server, for the one computer that is to pass changes between people writing in the same project at the same time. Nobody else needs it: Glaukopis works on its own. How to run it is in /usr/share/doc/glaukopis-server/server.md once installed.

The dictionaries are optional, and Glaukopis finds those of Hunspell as well (hunspell-en_us, hunspell-en_gb; hunspell-nb and hunspell-nn from the AUR), which serve for other languages too. Other Linux distributions are not covered yet.

Checking what you downloaded

SHA256SUMS lists the checksum of every file above. In the folder you downloaded to, sha256sum -c SHA256SUMS --ignore-missing on Linux or shasum -a 256 -c SHA256SUMS --ignore-missing on macOS checks them; on Windows, Get-FileHash in PowerShell shows a file's checksum to compare.

Reading on, and reporting

The guide to Glaukopis is installed with it and can be read on GitHub: docs/guide.md. Faults, surprises and wishes are welcome by mail to develop@robertemilberge.no, or as issues at github.com/polemistes/glaukopis. Say which file you installed and what you did when it went wrong.
