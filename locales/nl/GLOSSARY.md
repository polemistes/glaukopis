# De woorden van Glaukopis in het Nederlands

Dit is de Nederlandse keuze voor elk woord van `locales/GLOSSARY.md`. Elk
woord wordt in alle bestanden op dezelfde manier gebruikt.

## Aanspreekvorm en toon

- **Aanspreekvorm: je.** Dat is wat Nederlandstalige software vandaag
  doet (Microsoft, Apple, Google); het past bij de vriendelijke, gewone
  toon van het Engels. Onbeklemtoond: *je*, *je bibliotheek*, nooit *jij*
  of *jouw*, tenzij de nadruk het vraagt. Waar het kan, wordt de schrijver
  helemaal niet aangesproken: onpersoonlijk of met een infinitief.
- **Opdrachten in de infinitief**: *Opslaan*, *Verwijzing invoegen*,
  *Document binnenhalen*. Knoppen, menu's en tabbladen blijven ongeveer zo
  kort als het Engels.
- **Aanhalingstekens**: enkele, ‘…’; binnen een aanhaling dubbele “…”.
  Het beletselteken is `…`; het gedachtestreepje is `–` met spaties.
- **Toetsen** zoals een Nederlands toetsenbord ze schrijft: Ctrl, Shift,
  Alt, Enter, Esc, Tab, Backspace, Delete, Home, End, Page Up, Page Down,
  de pijltjestoetsen, de spatiebalk.
- **Meervoudsvormen**: `one` en `other`.
- **Samenstellingen met een naam of afkorting** krijgen een koppelteken:
  *Word-document*, *PDF-bestand*, *Zotero-bibliotheek*, *DOI-nummer*.

## Referenties en verwijzingen

| Engels | Nederlands |
| --- | --- |
| the library | **de bibliotheek** |
| reference | **referentie** (de); een *werk* |
| collection | **verzameling** (de) |
| attachment | **bijlage** (de) |
| the files of the library | **de bestanden van de bibliotheek**: een eigen weergave naast de referenties, met eigen mappen; een bestand hoort bij geen, één of meer referenties. Bestanden worden **opgenomen** in de eigen **opslag** van de bibliotheek, worden **toegewezen** aan een referentie; *niet toegewezen* is bij geen referentie. Het *doornemen* (going-through), zoals bij de losse verwijzingen, geeft de bestanden aan hun referenties |
| note | **notitie** (de) |
| citation | **verwijzing** (de), voluit **bronverwijzing**; nooit *citaat*, want dat is een aangehaalde tekst |
| quotation (de soort alinea) | **citaat** (het) |
| locator | **vindplaats** (de): pagina, hoofdstuk, vers, regel |
| lookup | **opzoeken**: gegevens van een referentie op het net vinden |
| loose citations | **losse verwijzingen**: verwijzingen in een tekst die van elders is binnengehaald, als zodanig herkend maar nog niet aan een referentie van de bibliotheek gekoppeld; ze worden **tot verwijzingen gemaakt** wanneer ze worden gekoppeld. Tot 2026-10 heetten ze *gevonden verwijzingen* |
