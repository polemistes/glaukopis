# Les mots de Glaukopis en français

Ce fichier dit quel mot français est choisi pour chaque mot propre à
l’application (voir `locales/GLOSSARY.md`), et comment on s’adresse à la
personne qui écrit. Un mot choisi ici est le même dans tous les fichiers.

## La forme d’adresse

- **Vous**, partout où il faut s’adresser à la personne : « Sélectionnez du
  texte… », « vos mots ». Jamais « tu ».
- **Les commandes à l’infinitif**, comme le font les logiciels en français :
  « Enregistrer », « Supprimer », « Ouvrir la carte ». Les boutons, les
  menus et les éléments de la palette sont des infinitifs ; les onglets et
  les titres sont des noms.
- Les indications (`.hint`) et les messages peuvent être des phrases
  entières, à l’indicatif ou à l’impératif de politesse.

## La typographie

- Les guillemets français « … », avec une espace fine insécable (U+202F)
  à l’intérieur : « { $name } ».
- Une espace fine insécable (U+202F) avant `;` `:` `!` `?`.
- L’apostrophe typographique ’ ; les points de suspension `…` ; le tiret
  demi-cadratin « – » pour les intervalles, le tiret cadratin « — » pour
  les incises.
- Les formes du pluriel : `one` (0 et 1), `many` (le million et au-delà,
  que la vérification exige) et `other`. La forme `many` s’écrit comme
  `other`.
- Les touches comme un clavier français les nomme : Ctrl, Maj, Alt,
  Entrée, Suppr, Échap, Retour arrière, Tab, Espace, Début, Fin,
  Page préc., Page suiv., Inser, flèches ← ↑ → ↓ (Alt+Maj+↑).

## Le travail

- **project** → le **projet** : un seul arbre d’éléments, dont l’élément du
  haut porte le nom du projet
- **tree** → l’**arbre** (l’arbre du projet ; « 3 arbres » sous un projet)
- **map** → la **carte** (une carte mentale ; « carte » suffit partout).
  Tout élément peut **s’ouvrir comme carte** ; on **remonte** ensuite à
  l’élément du dessus : « Remonter à « … » », le bouton **Remonter**.
- **the owl map** → la **carte de la chouette** : tous les projets en carte
  autour de la chouette, leurs dossiers comme étiquettes ; aussi la
  **carte des projets**. La chouette est celle d’Athéna, jamais un hibou.
- **element** → l’**élément** (tout élément peut s’imprimer comme
  document)
- **the centre** → le **centre**
- **the element in view** → l’**élément affiché** (le dossier affiché, sur la
  carte des projets)
- **the diagram** → le **diagramme**
- **the text** → le **texte** (la vue « texte »)
- **passage** → le **passage**
- **kind** → le **type** : le type d’un élément, d’un paragraphe, de mots.
  Un type est un sens, jamais une apparence.
- **look** → l’**aspect** : comment un type est composé dans le document
  (corps, interligne, italique…). Les aspects appartiennent à la mise en
  page.
- **the Look panel** → le volet **Aspect** : le volet à côté de l’aperçu, où
  se règle tout ce qui décide de l’aspect des pages (modèle, mise en page,
  citations). Ce qu’on y change est gardé comme les **modifications** propres
  du document par-dessus sa mise en page.
- **layout** → la **mise en page** (les **mises en page**) : comment se
  présente la page d’un document : les marges, les polices, les titres, les
  notes, les aspects des types. « Manuscrit » et « Livre de fiction » sont
  des mises en page. Une mise en page « à vous » est une de vos mises en
  page. C’est ce que l’interface appelait « format » avant l’arrivée des
  modèles (les fichiers et le code disent encore *format*).
- **format** → le **format** : seulement le format d’un fichier (Word, PDF,
  LaTeX…). Jamais pour la mise en page. (« Format » reste aussi le nom du
  menu des marques, comme en anglais.)
- **template** → le **modèle** : ce dont se compose un document d’un genre :
  quelles parties, dans quel ordre, quels types d’éléments et de passages il
  met sous la main, quelle mise en page et quel style de référence il
  apporte, ce qu’il exige (mots, mots-clés, anonymat), quels fichiers il
  produit. « Article de revue », « Manuscrit de roman » et celui d’une revue
  sont des modèles. Il se choisit dans les réglages du document d’un
  élément, et se transmet aux éléments du dessous.
- **pattern document** → le **document patron** : le document d’où Word et
  OpenDocument prennent leurs styles (anciennement « document modèle », mot
  qui revient désormais aux modèles).
- **style** → le **style** : le style de référence seulement (citations et
  bibliographie). Jamais pour l’aspect.
- **document settings** → les **réglages du document** : la fenêtre du
  document d’un élément (son modèle, ses informations, ses parties, son
  aspect, sa langue, la liste de contrôle). Menu : « Réglages du
  document… ».
- **details** (of a document) → les **informations** (titre, auteurs, date,
  mots-clés, identifiants)
- **part** → la **partie** : un type d’élément qui a sa place dans le
  document : le résumé, une dédicace, une annexe, la couverture. Ses places
  sont les **pages liminaires** (front matter), les **pages finales** (back
  matter) et la **couverture** (cover). Les parties que l’application fait
  elle-même : faux-titre, page de titre, mots-clés, table des matières…
- **parts of a window** (the sections chosen at the left) → les
  **rubriques** (« Rubriques de la fenêtre »), pour ne pas les confondre
  avec les parties du document.
- **requirements** → les **exigences** (de la revue, de l’éditeur, du
  modèle) ; **limit** → la **limite**
- **checklist** → la **liste de contrôle** : ce que le modèle exige, en
  regard du texte et de l’arbre
- **in hand** (kinds) → **sous la main** (les types que le modèle met sous
  la main)
- **document** → le **document**
- **the manuscript** → le **manuscrit**
- **the preview** → l’**aperçu**
- **export** → **exporter**, l’**exportation**
- **bring in** → **importer** (le français n’a pas de mot courant plus
  simple ; « importer » sert aussi pour Zotero)
- **project file** → le **fichier de projet** (un projet en un seul
  fichier)

## Références et citations

- **the library** → la **bibliothèque**
- **reference** → la **référence** (un ouvrage, un article, un chapitre)
- **collection** → la **collection**
- **attachment** → le **fichier joint**
- **the files of the library** → les **fichiers de la bibliothèque** : une
  réserve à eux, à côté des images, dans des dossiers à eux ; un fichier
  peut n’appartenir à aucune référence, à une ou à plusieurs. **assign** →
  **attribuer** (à une référence) ; **unassigned** → **sans référence** ;
  **the going-through** → le **passage en revue** (passer les fichiers en
  revue, pour les donner à leurs références)
- **note** → la **note**
- **citation** → la **citation** (une référence citée dans le texte, avec
  ses pages). Le type de paragraphe « quotation » s’appelle aussi
  « citation », comme dans les traitements de texte en français ; là où il
  faut distinguer, on dit « citation en retrait » ou « texte cité ».
- **cite** → **citer**
- **locator** → le **repère** (page, chapitre, vers, ligne)
- **lookup** → la **recherche en ligne** ; **chercher** (les détails d’une
  référence par DOI, ISBN ou recherche)
- **loose citations** → les **citations non liées** : des citations d’un
  texte venu d’ailleurs, reconnues comme telles mais pas encore **liées à
  une référence** de la bibliothèque ; on en **fait des citations**.
  Jusqu’au 2026-10-12 l’interface disait « citations reconnues ». Pas
  « citations libres », qui en français veut dire une citation non
  littérale.
- **bibliography** → la **bibliographie**

## Mots et marques

- **foreign words** → les **mots étrangers** (mots dans une autre langue)
- **title of a work** → le **titre d’œuvre**
- **term** → le **terme**
- **mention** → la **mention** (un mot dont on parle en tant que mot)
- **highlight** → le **surlignage** ; **surligner**
- **marks** → les **marques** : italique, gras, petites capitales,
  souligné, exposant, indice, barré, code
- **reference mark** → la **marque de référence** : un endroit de la prose
  marqué par un verset, une page ou un numéro d’édition (3:16, 327a) ; elle
  ne fait pas partie des mots. Pas « repère », qui est le locator d’une
  citation.
- **run** (paragraphs of one kind standing together) → la **suite** ; le
  **bracket** à sa gauche → le **crochet**
- **numbers** (of lines) → les **numéros** ; **numbering** → la
  **numérotation**
- **page break**, **column break**, **a break within a paragraph** → le
  **saut de page**, le **saut de colonne**, le **saut de ligne**
- **language tag** → le **code de langue** (« grc », « la », « de-CH »)

- **figure** → la **figure** (une image placée dans un texte, avec sa

- **caption** → la **légende**
- **pointer** → le **renvoi** (à une figure, un tableau, un élément, une

- **table** → le **tableau**
- **formula** → la **formule**
- **placing** → le **placement** (ici, en haut, sur le côté, flottant)

## Temps, commentaires, historique

- **timeline** → la **frise chronologique** (« la frise » quand c’est court) ;
  la **chronologie** est l’élément-tableau que la frise peut ajouter à la carte
- **when** → **Quand** (comme étiquette) ; le **moment** ou la **période**
  d’un élément dans une phrase
- **comment** → le **commentaire** ; **commenter**
- **thread** → le **fil** ; **settle** → **clore** (un fil clos), **reopen**
  → **rouvrir**
- **history** → l’**historique**
- **changes** → les **modifications** ; **review** → la **révision**
  (accepter ou rejeter une à une)
- **accept** / **reject** → **accepter** / **rejeter**
- **sharing** → le **partage** ; **working together** → **travailler
  ensemble** ; **join** → **rejoindre**

## Lecture et vérification

- **spelling** → l’**orthographe** ; **dictionary** → le **dictionnaire** ;
  **own words** → **vos mots** (« mes mots » dans une commande)
- **reading text** → **lire le texte**, la **lecture du texte** ; **OCR**

- **made searchable** → rendu **interrogeable** (le texte posé sous l’image

- **language package** → le **paquet de langue** : les dictionnaires

- **search** / **replace** → **rechercher** / **remplacer** ; **found** →

## Ce que vous écrivez, l’aperçu et l’aspect (0.2.3)

- **what you are writing** → **ce que vous écrivez** : le bouton au-dessus de
  l’aperçu nomme ce qu’est le document (« Article de revue », « Thèse ») ;
  la question du **sélecteur** (chooser) est « Qu’écrivez-vous ? ». Ce
  qu’est le document, c’est le modèle de son élément.
- **About this document** → **À propos de ce document** : la fenêtre de ce
  que le document dit de lui-même (informations, langue, liste de contrôle).
  Les « réglages du document » restent le nom de ce qu’on y règle.
- **chip** → la **pastille** : la petite étiquette au bord de la page de
  l’aperçu qui nomme la ligne pressée (texte, citation, titre, titre
  courant…) et ouvre l’Aspect à sa ligne. Pas « étiquette », que la carte
  de la chouette emploie déjà pour les dossiers. Le réglage dit « nommer
  les lignes ».
- **running head** → le **titre courant** ; **header** / **footer** → l’**en-tête**
  / le **pied de page** ; leurs **places** (left, centre, right) → les
  **emplacements** (gauche, centre, droite).
- **scope** (where the changes of Look hold) → « Ces modifications valent
  pour » : tout le document, ou seulement un élément.

## La lecture des PDF et des numérisations (0.2.3)

- **the summary** (of a reading, as the dialog opens) → la **vue
  d’ensemble** (« Retour à la vue d’ensemble »). Jamais « résumé », qui est
  l’abstract d’un document.
- **the pages** (the workbench) → les **pages** : la **bande** des petites
  pages en haut (strip), et les trois **panneaux** de la page affichée.
- **what the pages take** → **ce que prennent les pages** (le texte du PDF,
  une lecture par Tesseract, ou selon la qualité du texte) ; **how Tesseract
  reads** → **comment Tesseract lit**.
- **try** (a page) → **essayer** ; a page **tried** → une page **essayée** ;
  a **trial** → un **essai** ; **Tried with** → « Essayée avec ».
- **confidence** → la **confiance** de Tesseract : **Confiance faible**,
  **Bonne confiance**, **Confiance élevée** (73 %), avec une espace fine
  insécable avant %.
- **unsure words** → les **mots incertains**.
- **stretch** (pages read alike) → la **plage** (de pages), dessinée en
  **bandeau** au-dessus de la bande des pages.
- **read poorly** → **mal lue** (une page sous 80 %).
- **what is made of it** → **ce qu’on en fait** (la forme gardée, un arbre
  par ses titres ou par ses pages, les marques de page).
- **Gothic type** → les **caractères gothiques** (l’impression allemande et
  scandinave d’autrefois) ; **Fraktur** reste le nom du caractère et du
  modèle : « le modèle Fraktur », « Fraktur (caractères gothiques) ».

## La fenêtre, l’aspect et les lignes (après 0.2.4)

Ces mots remplacent, là où ils diffèrent, ceux de plus haut : le
**panneau** (une moitié de l’écran partagé) est désormais un **côté** ; le
volet latéral est le **volet du document** ; « À propos de ce document »
est devenu **Propriétés du document** ; « Ouvrir comme carte » est devenu
**Entrer**.

- **the list** → la **liste** (la liste des projets, à gauche : l’arbre de
  tous les projets et de tous les dossiers)
- **the start screen** → l’**écran d’accueil** (quand aucun projet n’est
  ouvert)
- **side** → le **côté** : chaque côté de la fenêtre a son projet, son
  chemin et sa barre d’icônes. « Fermer ce côté », « Intervertir les
  côtés ». Pas « panneau » ni « volet ».
- **the path** → le **chemin** (en haut de chaque côté : où l’on est dans
  l’arbre) ; « Plus du chemin » pour les noms cachés derrière « … »
- **Split view** → **Vue scindée** ; le bouton court **Split** →
  **Scinder**. Pas « partagée », qui est le mot du partage avec d’autres.
- **enter** (an element) → **entrer** (dans un élément : il devient
  l’élément affiché) ; « Entrer », « Entrer à côté » ; on **remonte**
  comme avant. **Open beside** → **Ouvrir à côté**.
- **the typesetting pane** → le volet **Composition** (la **composition**) :
  les pages du côté choisi, telles qu’elles s’imprimeront, avec l’Aspect à
  côté. « Masquer la composition ». Pas « mise en pages », trop proche de
  la mise en page (layout).
- **the document pane** → le **volet du document** (références, images,
  commentaires, citations non liées, historique, modifications) ; son
  bouton dans la barre : **Document**.
- **zoom** → le **zoom** ; **Fit the width** → **Ajuster à la largeur** ;
  « 100 % » avec une espace fine insécable.
- **Marks** (the menu) → **Marques**, comme plus haut ; **the marks of
  whitespace** (¶, ↵) → les **caractères invisibles**, comme les
  traitements de texte en français.
- **hard space** → l’**espace insécable** (féminin, comme en typographie :
  « une espace insécable »)
- **Inline number** → le **numéro dans la ligne** (ce qu’on insère : 3:16,
  327a). Les **marques de référence** restent le nom de ces numéros dans
  la mise en page (« Les marques de référence sont rendues »).
- **clone** → le **clone** ; **cloner** : « Cloner un autre élément… »,
  « Clone de « … » », « Aller à l’original », « Ne plus être un clone »
- **sub-elements** → les **sous-éléments** ; **child element** →
  **sous-élément** ; **sibling element** → **élément de même niveau**
- **fold** / **unfold** → **replier** / **déplier**, comme plus haut
- **Time stamp…** → **Datation…** : le moment ou la période d’un élément,
  comme l’historien date un fait. « Rien n’est encore daté. »
- **image** → l’**image**, comme plus haut (l’anglais dit désormais
  *image* lui aussi)
- **look chip** → la **pastille d’aspect** (voir *chip* plus haut)
- **Document properties** → **Propriétés du document** ; **Document type**
  → le **type de document** : ce qu’est le document, c’est-à-dire son
  modèle (« Article de revue », « Thèse »). « Type » reste aussi le mot de
  *kind* : un type de document, un type de paragraphe, un type de mots.
- **Paragraph kind** / **Words kind** → **Type de paragraphe** / **Type de
  mots**
- **Default document type**, **Default look**, **Default citation style** →
  **Type de document par défaut**, **Aspect par défaut**, **Style de
  citation par défaut** ; **None** → **Aucun**
- **Key** (of a kind, Ctrl+Alt+0–9) → la **touche** ; **None** → **Aucune**
- **contributor** → le **contributeur** ; **role** → le **rôle** ; les
  trois rôles : **Auteur**, **Éditeur scientifique**, **Traducteur**.
  « Éditeur » seul est le *publisher* (l’identifiant), d’où « éditeur
  scientifique », comme dans les catalogues de bibliothèque.
- **Edited by …** → « Édité par … » ; **Translated by …** → « Traduit
  par … » ; **Edited and translated by …** → « Édité et traduit par … ».
  « Éditer » au sens d’établir un texte pour le publier, qui vaut pour une
  édition critique comme pour un volume collectif, là où « Texte établi
  par » ne vaut que pour la première et « Sous la direction de » que pour
  le second.
- **Editors and translators** (Look, the front page) → **Éditeurs
  scientifiques et traducteurs**
- **Front page** (Look) → la **Première page**, comme plus haut ;
  **Anonymize the front page** → **Anonymiser la première page** ;
  **Anonymous** (the requirement) → **Anonyme**
- **Line numbering from here** → **Numérotation des lignes à partir
  d’ici** ; **Numbering of this line** → **Numérotation de cette ligne** ;
  **Count the lines of** → **Compter les lignes de** (« Tous les types »,
  ou un seul)
- **Counted** → **Comptée** (la ligne) ; **Its number is shown** → **Son
  numéro est affiché** : **Comme les autres**, **Toujours**, **Jamais**
- **annotation** → l’**annotation** (un mètre, le numéro d’une autre
  édition, dans la marge) : « Annotation dans la marge de droite » ;
  **Annotations on the** → **Les annotations se placent**, comme « Les
  numéros se placent » ; **Other side from the numbers** → **Du côté
  opposé aux numéros**
- **Begins where the line before ended** → **Commence où la ligne
  précédente s’arrête** (la seconde moitié d’un vers partagé entre deux
  personnages)
- **Indentation step** → le **retrait par tabulation** : la longueur dont
  Tab met un paragraphe en retrait. Pas « pas de retrait », qui se lit
  « aucun retrait ». **one step in** / **out** → **augmenter** /
  **diminuer le retrait**
- **Indent first line** → **Retrait de la première ligne**

## Un fichier dans un côté, les onglets, les images, les cartes mentales (0.2.8)

- **a file in a view** → un **fichier affiché dans un côté** : un côté de
  la fenêtre montre un fichier de la bibliothèque, PDF ou image, au lieu
  d’une carte. **the viewer** (sa barre et ses pages) → la **visionneuse**,
  le mot des logiciels en français ; dans l’interface on dit plutôt « le
  fichier », « dans un fichier » (la place des touches).
- **Show the file** → **Afficher le fichier** ; **the document of the
  other side** → **le document de l’autre côté**
- **tab** → l’**onglet**, comme plus haut ; **the tabs of a project** →
  les **onglets du projet** : « Ajouter aux onglets d’un projet… », « Les
  onglets de { $name } », « Fermer l’onglet », « Fermer les autres
  onglets », « Ouvrir de nouveau dans un nouvel onglet », « N’est plus
  dans la bibliothèque »
- **bookmark** → le **signet**, le mot des lecteurs de PDF (Acrobat,
  Okular) ; pas « marque-page », qui est celui des navigateurs. « Marquer
  cet endroit », « Le nom du signet », « Supprimer ».
- **the contents of a file** (its own table of contents) → la **table des
  matières** du fichier ; **Bookmarks and contents** → **Signets et table
  des matières**
- **drawn** (pages) → **dessinées** : « Cette page n’a pas pu être
  dessinée », « Dessin de 12 pages pour l’impression… », comme le dit déjà
  la lecture des PDF
- **locked** (a file that asks for a password) → **demande un mot de
  passe**
- **zoom** → le **zoom**, comme plus haut ; **As wide as the view** →
  **Ajuster à la largeur**, comme dans la composition ; **The whole image
  in the view** → **L’image entière** ; **Zoom, in percent** → **Zoom, en
  pourcentage** ; « 100 % » avec une espace fine insécable
- **Go to page** → **Aller à la page** ; **Page 3 of 271** → **Page 3
  sur 271**, le numéro imprimé entre parenthèses après
- **Edit** (an image) → **Modifier** ; **the image editor** → la
  **modification d’une image**. Ses actes : **Turn left** / **Turn right**
  → **Tourner à gauche** / **Tourner à droite** ; **Flip sideways** /
  **Flip upside down** → **Retourner horizontalement** / **Retourner
  verticalement**, comme les visionneuses d’images ; **Crop** →
  **Recadrer** (pas « rogner », le mot de Word) ; **Cut to 800 × 600 of
  1600 × 1200** → **Recadré à 800 × 600 sur 1600 × 1200** ; **Brightness**
  → **Luminosité** ; **Contrast** → **Contraste** ; **Saturation** →
  **Saturation** ; **As it was** → **Comme à l’origine** (un curseur remis
  à 100 %) ; **Start again** → **Recommencer** ; **Keep as a new file** →

Zotero, CSL, Markdown, Org ; les noms de formats de fichier (DOCX, ODT, PDF,

référence (APA, Chicago, MLA) ; DOI, ISBN, ISSN, ORCID, arXiv, URL ; les noms
des projets dont Glaukopis est fait, et de leurs licences.
