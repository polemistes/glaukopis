# Les mots de Glaukopis en français

Ce fichier dit quel mot français est choisi pour chaque mot propre à
l’application (voir `locales/GLOSSARY.md`), et comment on s’adresse à la
personne qui écrit. Un mot choisi ici est le même dans tous les fichiers.

## La forme d’adresse

- **Vous**, partout où il faut s’adresser à la personne : « Sélectionnez du
  texte… », « vos mots ». Jamais « tu ».
- **Les commandes à l’infinitif**, comme le font les logiciels en français :
  « Enregistrer », « Supprimer », « Ouvrir la carte ». Les boutons, les
  menus et les éléments de la palette sont des infinitifs ; les onglets et
  les titres sont des noms.
- Les indications (`.hint`) et les messages peuvent être des phrases
  entières, à l’indicatif ou à l’impératif de politesse.

## La typographie

- Les guillemets français « … », avec une espace fine insécable (U+202F)
  à l’intérieur : « { $name } ».
- Une espace fine insécable (U+202F) avant `;` `:` `!` `?`.
- L’apostrophe typographique ’ ; les points de suspension `…` ; le tiret
  demi-cadratin « – » pour les intervalles, le tiret cadratin « — » pour
  les incises.
- Les formes du pluriel : `one` (0 et 1), `many` (le million et au-delà,
  que la vérification exige) et `other`. La forme `many` s’écrit comme
  `other`.
- Les touches comme un clavier français les nomme : Ctrl, Maj, Alt,
  Entrée, Suppr, Échap, Retour arrière, Tab, Espace, Début, Fin,
  Page préc., Page suiv., Inser, flèches ← ↑ → ↓ (Alt+Maj+↑).

## Le travail

- **project** → le **projet** : un seul arbre d’éléments, dont l’élément du
  haut porte le nom du projet
- **tree** → l’**arbre** (l’arbre du projet ; « 3 arbres » sous un projet)
- **map** → la **carte** (une carte mentale ; « carte » suffit partout).
  Tout élément peut **s’ouvrir comme carte** ; on **remonte** ensuite à
  l’élément du dessus : « Remonter à « … » », le bouton **Remonter**.
- **the owl map** → la **carte de la chouette** : tous les projets en carte
  autour de la chouette, leurs dossiers comme étiquettes ; aussi la
  **carte des projets**. La chouette est celle d’Athéna, jamais un hibou.
- **element** → l’**élément** (tout élément peut s’imprimer comme
  document)
- **the centre** → le **centre**
- **the element in view** → l’**élément affiché** (le dossier affiché, sur la
  carte des projets)
- **the diagram** → le **diagramme**
- **the text** → le **texte** (la vue « texte »)
- **passage** → le **passage**
- **kind** → le **type** : le type d’un élément, d’un paragraphe, de mots.
  Un type est un sens, jamais une apparence.
- **look** → l’**aspect** : comment un type est composé dans le document
  (corps, interligne, italique…). Les aspects appartiennent à la mise en
  page.
- **the Look panel** → le volet **Aspect** : le volet à côté de l’aperçu, où
  se règle tout ce qui décide de l’aspect des pages (modèle, mise en page,
  citations). Ce qu’on y change est gardé comme les **modifications** propres
  du document par-dessus sa mise en page.
- **layout** → la **mise en page** (les **mises en page**) : comment se
  présente la page d’un document : les marges, les polices, les titres, les
  notes, les aspects des types. « Manuscrit » et « Livre de fiction » sont
  des mises en page. Une mise en page « à vous » est une de vos mises en
  page. C’est ce que l’interface appelait « format » avant l’arrivée des
  modèles (les fichiers et le code disent encore *format*).
- **format** → le **format** : seulement le format d’un fichier (Word, PDF,
  LaTeX…). Jamais pour la mise en page. (« Format » reste aussi le nom du
  menu des marques, comme en anglais.)
- **template** → le **modèle** : ce dont se compose un document d’un genre :
  quelles parties, dans quel ordre, quels types d’éléments et de passages il
  met sous la main, quelle mise en page et quel style de référence il
  apporte, ce qu’il exige (mots, mots-clés, anonymat), quels fichiers il
  produit. « Article de revue », « Manuscrit de roman » et celui d’une revue
  sont des modèles. Il se choisit dans les réglages du document d’un
  élément, et se transmet aux éléments du dessous.
- **pattern document** → le **document patron** : le document d’où Word et
  OpenDocument prennent leurs styles (anciennement « document modèle », mot
  qui revient désormais aux modèles).
- **style** → le **style** : le style de référence seulement (citations et
  bibliographie). Jamais pour l’aspect.
- **document settings** → les **réglages du document** : la fenêtre du
  document d’un élément (son modèle, ses informations, ses parties, son
  aspect, sa langue, la liste de contrôle). Menu : « Réglages du
  document… ».
- **details** (of a document) → les **informations** (titre, auteurs, date,
  mots-clés, identifiants)
- **part** → la **partie** : un type d’élément qui a sa place dans le
  document : le résumé, une dédicace, une annexe, la couverture. Ses places
  sont les **pages liminaires** (front matter), les **pages finales** (back
  matter) et la **couverture** (cover). Les parties que l’application fait
  elle-même : faux-titre, page de titre, mots-clés, table des matières…
- **parts of a window** (the sections chosen at the left) → les
  **rubriques** (« Rubriques de la fenêtre »), pour ne pas les confondre
  avec les parties du document.
- **requirements** → les **exigences** (de la revue, de l’éditeur, du
  modèle) ; **limit** → la **limite**
- **checklist** → la **liste de contrôle** : ce que le modèle exige, en
  regard du texte et de l’arbre
- **in hand** (kinds) → **sous la main** (les types que le modèle met sous
  la main)
- **document** → le **document**
- **the manuscript** → le **manuscrit**
- **the preview** → l’**aperçu**
- **export** → **exporter**, l’**exportation**
- **bring in** → **importer** (le français n’a pas de mot courant plus
  simple ; « importer » sert aussi pour Zotero)
- **project file** → le **fichier de projet** (un projet en un seul
  fichier)

## Références et citations

- **the library** → la **bibliothèque**
- **reference** → la **référence** (un ouvrage, un article, un chapitre)
- **collection** → la **collection**
- **attachment** → le **fichier joint**
- **the files of the library** → les **fichiers de la bibliothèque** : une
  réserve à eux, à côté des images, dans des dossiers à eux ; un fichier
  peut n’appartenir à aucune référence, à une ou à plusieurs. **assign** →
  **attribuer** (à une référence) ; **unassigned** → **sans référence** ;
  **the going-through** → le **passage en revue** (passer les fichiers en
  revue, pour les donner à leurs références)
- **note** → la **note**
- **citation** → la **citation** (une référence citée dans le texte, avec
  ses pages). Le type de paragraphe « quotation » s’appelle aussi
  « citation », comme dans les traitements de texte en français ; là où il
  faut distinguer, on dit « citation en retrait » ou « texte cité ».
- **cite** → **citer**
- **locator** → le **repère** (page, chapitre, vers, ligne)
- **lookup** → la **recherche en ligne** ; **chercher** (les détails d’une
  référence par DOI, ISBN ou recherche)
- **loose citations** → les **citations non liées** : des citations d’un
  texte venu d’ailleurs, reconnues comme telles mais pas encore **liées à
  une référence** de la bibliothèque ; on en **fait des citations**.
  Jusqu’au 2026-10-12 l’interface disait « citations reconnues ». Pas
  « citations libres », qui en français veut dire une citation non
  littérale.
- **bibliography** → la **bibliographie**

## Mots et marques

- **foreign words** → les **mots étrangers** (mots dans une autre langue)
- **title of a work** → le **titre d’œuvre**
- **term** → le **terme**
- **mention** → la **mention** (un mot dont on parle en tant que mot)
- **highlight** → le **surlignage** ; **surligner**
- **marks** → les **marques** : italique, gras, petites capitales,
  souligné, exposant, indice, barré, code
- **reference mark** → la **marque de référence** : un endroit de la prose
  marqué par un verset, une page ou un numéro d’édition (3:16, 327a) ; elle
  ne fait pas partie des mots. Pas « repère », qui est le locator d’une
  citation.
- **run** (paragraphs of one kind standing together) → la **suite** ; le
  **bracket** à sa gauche → le **crochet**
- **numbers** (of lines) → les **numéros** ; **numbering** → la
  **numérotation**
- **page break**, **column break**, **a break within a paragraph** → le
  **saut de page**, le **saut de colonne**, le **saut de ligne**
- **language tag** → le **code de langue** (« grc », « la », « de-CH »)

## Images, figures, tableaux et formules

- **picture** → l’**image** (le fichier, dans la réserve)
- **the store** → la **réserve** (où vivent toutes les images ; la vue de la
  barre s’appelle **Images**)
- **figure** → la **figure** (une image placée dans un texte, avec sa
  légende, sa largeur et son numéro)
- **caption** → la **légende**
- **pointer** → le **renvoi** (à une figure, un tableau, un élément, une
  page)
- **table** → le **tableau**
- **formula** → la **formule**
- **placing** → le **placement** (ici, en haut, sur le côté, flottant)

## Temps, commentaires, historique

- **timeline** → la **frise chronologique** (« la frise » quand c’est court) ;
  la **chronologie** est l’élément-tableau que la frise peut ajouter à la carte
- **when** → **Quand** (comme étiquette) ; le **moment** ou la **période**
  d’un élément dans une phrase
- **comment** → le **commentaire** ; **commenter**
- **thread** → le **fil** ; **settle** → **clore** (un fil clos), **reopen**
  → **rouvrir**
- **history** → l’**historique**
- **changes** → les **modifications** ; **review** → la **révision**
  (accepter ou rejeter une à une)
- **accept** / **reject** → **accepter** / **rejeter**
- **sharing** → le **partage** ; **working together** → **travailler
  ensemble** ; **join** → **rejoindre**

## Lecture et vérification

- **spelling** → l’**orthographe** ; **dictionary** → le **dictionnaire** ;
  **own words** → **vos mots** (« mes mots » dans une commande)
- **reading text** → **lire le texte**, la **lecture du texte** ; **OCR**
  reste OCR là où l’anglais l’écrit
- **made searchable** → rendu **interrogeable** (le texte posé sous l’image
  des pages)
- **language package** → le **paquet de langue** : les dictionnaires
  d’orthographe et les fichiers de langue de l’OCR, importés d’un serveur ou
  d’un dossier
- **search** / **replace** → **rechercher** / **remplacer** ; **found** →
  **trouvé**

## L’interface

- **the rail** → la **barre** (la barre de gauche : Projets, Bibliothèque,
  Images, Réglages)
- **the panel at the side** → le **volet** (le volet latéral : références,
  images, commentaires, modifications, historique)
- **pane** → le **panneau** (une moitié de l’écran partagé)
- **the palette** → la **palette** (la palette de commandes)
- **the writing tools** → les **outils d’écriture**
- **fold** / **unfold** → **replier** / **déplier**
- **settings** → les **réglages**
- **data directory** → le **dossier des données**
- **credits** → les **crédits** (« Crédits et licences »)
- **your usual** (layout, style, template) → **votre choix habituel**, qui
  s’accorde avec les trois
- **tab** → l’**onglet** ; **button** → le **bouton** ; **menu** → le
  **menu** ; **shortcut** → le **raccourci**
- **select** → **sélectionner** ; **selection** → la **sélection**
- **choose** → **choisir** ; **pick** → **choisir**
- **press** (a button, a key) → **appuyer sur** ; **click** → **cliquer**
- **drag** → **glisser**, **faire glisser** ; **drop** → **déposer**

## Les noms qui ne se traduisent pas

Glaukopis ; Pandoc, Typst, Tesseract, Hunspell, LaTeX, LuaLaTeX, BibLaTeX,
Zotero, CSL, Markdown, Org ; les noms de formats de fichier (DOCX, ODT, PDF,
EPUB, RTF, HTML, SVG, PNG) ; les noms de polices ; les noms de styles de
référence (APA, Chicago, MLA) ; DOI, ISBN, ISSN, ORCID, arXiv, URL ; les noms
des projets dont Glaukopis est fait, et de leurs licences.
