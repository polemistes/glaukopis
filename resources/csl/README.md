# Reference styles

The files in `styles/` are taken unchanged from the
[Citation Style Language styles repository](https://github.com/citation-style-language/styles)
and are licensed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Each file names its authors.

`index.json` lists every style of that repository by id and title, so that any of
them can be found by name and fetched when wanted. `locator-terms.json` holds the
words for "page", "chapter" and the like in each language, taken from the
[CSL locales repository](https://github.com/citation-style-language/locales),
under the same licence.

Fetched 2026-09-27. `python3 scripts/update-csl.py` makes them anew.
