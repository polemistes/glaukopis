3. **The text view.** `app.css`: `.prose span.linemark[data-continues] { display: inline-block; width: var(--continues, calc(4 * var(--step))); }`; a plugin in a new `src/lib/editor/continues.ts`, added in `plugins.ts`, which after each update of the view (a `view` plugin with `update(view)`, in a `requestAnimationFrame`) finds every mark with `continues`, measures the line before (`view.coordsAtPos(end).right` of that line less the left edge of its paragraph's content box, `view.nodeDOM(paragraphPos).getBoundingClientRect().left` plus its padding) and sets `--continues` on the mark's element (`view.nodeDOM(markPos)`) to that width plus one em of the text. Where nothing can be measured, the fallback width holds. `e2e/verse.mjs` proves it: the second line's first word begins within two pixels of where the first line's last word ends plus an em.
4. **The step.** `formats/mod.rs`: `Text.indent_step: Length`, `Length::cm(0.6)` in `Default`, in `sanitise` bounded 0.1–5 cm; a row `length(t('format-indent-step'), 'text.indentStep')` in `paragraphRows` after *Indent first line*; the text view is told it with the layout's numbers: `NumbersLayout` gains `step: number` (points), `RichText.svelte` sets `--step` on the editor's root (`style="--step: 17pt"`, as `drawnWith` reaches it), and `app.css` uses `var(--step)` where it has `1.5em` for `--indent` (lines 1262, 1269, 531). `kinds.ts` is untouched.
5. **The page, Typst.** `typst.rs` about 787: `gk-line(kind, indent, after: none, n: none, margin: none, side: "left", body)`: within `context`, `let more = if after == none { 0pt } else { measure(after).width + 1em }`, the block's inset `indent * {step} + more`, the number and the margin words placed at `{inset} + indent * {step} + more` as they are at `{inset} + indent * 1.5em` today; `{step}` is `f.text.indent_step`. For prose lines, `#let gk-after(prev) = {{ box[]; context h(measure(prev).width + 1em) }}` beside `gk-beside`.
