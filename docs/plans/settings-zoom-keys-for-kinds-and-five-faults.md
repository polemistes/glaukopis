## Stage 4 — keys for the kinds

Files: `crates/core/src/templates/mod.rs`, `src/lib/api/templates.ts` (and `contract.generated.ts`, regenerated by the contract test in `src-tauri`), `resources/templates/*.json`, `scripts/check-templates.mjs`, `src/lib/shell/keys.svelte.ts`, `src/lib/editor/keys.ts`, `src/lib/editor/commands.ts` (`setKind`), `src/lib/editor/WritingTools.svelte`, `src/lib/look/LookPanel.svelte`, `src/lib/document/TemplateEditor.svelte`, `locales/*/keys.ftl`, `look.ftl`, `editor.ftl`, `docs/guide.md`, `e2e/keys.mjs`.

1. **The data.** `Template` gains `kind_keys: BTreeMap<String, String>` (`#[serde(default, skip_serializing_if = "BTreeMap::is_empty")]`), digit → kind id, with `"0"` → `"text"` understood even when absent. `api/templates.ts` mirrors it (`kindKeys: Record<string, string>`). `check-templates.mjs` checks that every kind named is among the type's `passageKinds` or the catalogue's, and that `"0"` is `"text"` where given. The templates that ship get their digits: the plain type and the articles 1 Quotation, 2 Verse, 3 Bullet list, 4 Numbered list, 5 Code, 6 Epigraph, 7 Attribution; a play adds 1 Speaker, 2 Stage direction, 3 Verse, 4 Quotation; a screenplay 1 Scene, 2 Action, 3 Character, 4 Dialogue, 5 Parenthetical, 6 Transition; a glossary-like type Headword and Gloss where it has them. Read each type's `passageKinds` and assign only kinds it has; say the assignments in the report.
2. **The keys.** `keys.svelte.ts` gains ten entries `writing-kind-0` … `writing-kind-9`, keys `Ctrl+Alt+0` … `Ctrl+Alt+9`, place `writing`, with words in `keys.ftl` (`keys-writing-kind` = *The kind of paragraph the document type gives the digit* / nb). `editor/keys.ts` binds them to a command that looks up the digit in the document type of the element being written (the type in force for that element: `documents.templateFor`/`templateCached` as `WritingTools.svelte` about 211 reaches it) and runs `setKind(id, own)` from `commands.ts`; a digit without a kind does nothing. Confirm the AltGr guard at `keys.svelte.ts` about 396 covers these entries (it is in the dispatcher, before matching); add a test in `keys.test.ts` that a chord with `AltGraph` set is not matched.
3. **In Look.** Under *Paragraph kinds*, each kind's box gets a row *Key* (`look-kind-key` = *Key* / *Tast*): a chooser of *None* and the ten digits shown as `Ctrl+Alt+n`; choosing writes the type's `kindKeys` through the document type's editing path (`TemplateEditor.svelte`'s way of changing a type: a type that comes with Glaukopis becomes a copy of the writer's own, as `templates.ts`'s head says); a digit taken from another kind is removed from that kind. Where the document's type is read only (not the writer's own and not copied yet), the chooser still works and makes the copy.
4. **Shown.** `WritingTools.svelte`'s Paragraph kind menu shows the key beside each kind (`shortcut:`), from the type in force; the key sheet (`KeySheet.svelte`) lists the ten with the current type's kinds. `TemplateEditor.svelte` shows the keys in its kinds section, read-only or editable as its kinds are.
5. **Scripts.** `e2e/keys.mjs`: Ctrl+Alt+1 in a plain document makes the paragraph a quotation, Ctrl+Alt+0 text again; `e2e/look.mjs`: the Key row of Verse set to 2, the menu shows it, Ctrl+Alt+2 makes verse.

Verify: `cargo test` (capped), `node scripts/check-templates.mjs`, `pnpm check`, `pnpm test`, the two scripts, `e2e/templates.mjs`, `e2e/what.mjs`. Commit.
