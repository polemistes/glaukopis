## Vocabulary

- *The element in view*: `at`, what a side has entered; the tree the diagram and the text draw.
- *The document* of a side: the element whose document the side's typesetting, numbers, Look and keys are of. The marked element where the project has one and it is there; else the element in view. In code `document` beside `at`; never `at` for it from now on.
- *The mark*: `OpenProject.document`, the id of the element marked, or null.
- *The sign*: the open book of the Typesetting button (`BookOpenText`), shown where the mark is.

1. `layout.ts`: `StoredView.document?: string` ("the element marked as the document, where one is"); `Memory.document: string | null`; `readMemory` reads it where it is a non-empty string; `toStore` writes it where `inView(elements, memory.document)`, else leaves it out. The one rule, pure and tested:

   ```ts
   /**
    * The document of a side: the element marked as the document where the
    * project has one and it is there, else the element in view (record
    * 0081). The mark is tested against the elements, not against the way
    * down to the element in view: it holds wherever one is.
    */
   export function documentOf(marked: string | null, elements: Elements, at: string): string {
     return marked && elements.has(marked) ? marked : at;
   }
   ```

   Tests: no mark gives `at`; a mark that is there gives the mark, with `at` within it, beside it and above it; a mark that is gone gives `at`; `toStore` keeps a mark that is there and drops one that is not; `readMemory` reads an old view without one as null.

3. `SideView.svelte`: the effect that saves the project's own view (about line 110, `void Object.values(open.cameras)` …) reads `open.document` as well, so that a mark set or taken off is saved a moment after.
