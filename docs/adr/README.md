# The records, and which hold

This is the index of the decision records in this folder, with a word on whether each still holds. A record's status is judged by the records that came after it: a later record may replace an earlier one wholly or in part without the earlier one saying so, and a record's own addenda may amend its body without the body being changed. When a record is added that changes an earlier one, this file must be brought up to date with it.
